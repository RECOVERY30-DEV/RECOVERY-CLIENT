# Final Report Checklist

최종 응답이나 PR 설명 전에 결과를 빠짐없이 정리합니다.

## Include

- 변경한 주요 영역
- 문서 영향
- 실행한 검증 명령과 결과
- 실행하지 못한 검증과 이유
- 남은 위험과 후속 작업

반복 가능한 패턴이 실제로 발견된 경우에만 아래 내용을 추가합니다.

- 자동화 후보 이름
- 반복 근거
- 추천 형태: rule, checklist, recipe, skill, script, hook, CI
- 실행 조건과 필요한 검증

## Avoid

- 확인하지 않은 내용을 완료처럼 말하지 않습니다.
- 실패한 검증을 생략하지 않습니다.
- 관련 없는 변경을 함께 처리했다고 말하지 않습니다.
- 승인 없이 commit, push, PR, merge가 완료됐다고 표현하지 않습니다.
- 단순한 일회성 작업을 억지로 skill 후보로 만들지 않습니다.
